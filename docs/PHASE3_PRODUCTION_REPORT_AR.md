## اختبارات Live بعد تطبيق الترحيل — PASS

نُفذت `tests/phase3-live.acceptance.sql` على Live؛ انتهت المعاملة بـROLLBACK. ليست محاكاة PGlite ولا تنفيذ service_role بوصفه المستخدم المختبر: استُخدم `SET LOCAL ROLE authenticated` مع هويتي مؤسستين موجودتين، ثم anon للفحص العام.

شملت: الإنشاء بالمقاس الموحد واللون المركب، توليد اسم العرض من الخادم، التوافق مع الطلب القديم، رفض المكونات المكررة وعكس ترتيب المجموعة المكررة، rollback عند فشل باركود مكرر، ثبات الباركود والهدف، عزل القراءة والتعديل والحذف والإضافة/RPC بين مؤسستين، قراءة الموظف ومنع كتابته وRPC الإنشاء، تقييد كتابة مخزون المدير بفرعه، منع anon من قراءة الجداول الخام واستدعاء الإنشاء، واستمرار get_store_products.

اختُبر فعلياً عبر engine_sync_sale: الكمية 10 والمحجوز 7، رفض 4 ونجاح 3، ثم التحقق من بقاء الكمية 7 والمحجوز 7. جميع المبيعات التجريبية أُلغيت بالـRollback. هذا اختبار انحدار داخل معاملة، وليس اختبار سباق متعدد الاتصالات.

- أُزيل vercel.json التجريبي من جذر المستودع لاستعادة بناء Next.js الحقيقي وإعدادات المشروع الأصلية؛ لا نشر لصفحة Mock بدلاً من التطبيق.

- main يحتوي snapshot أقدم بتاريخ Git منفصل (450b1c6). رُبط التاريخان على فرع الجلسة بدمج يحافظ على snapshot التطبيق الحالي. لا حذف لفرع، ولا Reset، ولا Force Push، ولا انتقال إلى main أو دفع مباشر له. الـPR إلى main يوضح أن الفارق يشمل أيضاً تحديثات التطبيق السابقة الموجودة أصلاً على الإنتاج، وليست كلها Phase 3.
- اختبارات المستودع: 565 ناجحة، صفر فشل وصفر تخطٍّ.
- بناء Next.js المحلي ناجح مع font mock محلي وSupabase placeholders بسبب قيود الشبكة؛ لا تغيير لمصدر خط الإنتاج ولا لمتغيراته.

## حالة هذه الوثيقة

كُتبت عند تجهيز Commit الإصدار، بعد نجاح ترحيل Live واختباراته وقبل دمج PR/نشر Vercel. رقم PR وSHA الإنتاج وحالة النشر والتحقق بعده تُوثّق في رسالة التسليم النهائية بناء على نتائج الأدوات؛ هذه الوثيقة لا تدعي أن النشر اكتمل قبل حدوثه.

## حدود الإثبات

لا اختبار بيع دائم من حساب عميل، ولا جلسة POS متصفح موثقة بعد النشر، ولا طابعة أو قارئ HID فعلي. HTTP لا يثبت نجاح سير عمل موثّق. لا تغيير لموقع الشركة أو مفاتيح الشحن أو MockMode الشحن. عند مشكلة واجهة يُرجع إصدار التطبيق الموافق مع إبقاء العمود والبيانات الجديدة؛ لا DROP COLUMN أو حذف تركيبات أو تغيير باركوداتها للتراجع.
